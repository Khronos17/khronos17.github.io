# Privacy Policy

Last updated: 2026-11-19

Team Daily Radio ("the app") is a personal, non-commercial tool run by one person (the operator) to maintain a daily team music playlist on the operator's own YouTube channel.

## What Google user data the app accesses
- The app is authorized only by the operator, on the operator's own Google account.
- Through the YouTube Data API it searches public YouTube videos, reads the operator's own playlists, and creates, updates and removes items in those playlists.
- It may read aggregated, anonymous YouTube Analytics statistics for the operator's own playlists (for example view counts and average view duration).
- It does not access any other person's Google account, email, contacts or personal data.

## How the data is used
The data is used only to build and update the team playlist. It is not used for advertising, not sold, and not shared with anyone.

## Storage and security
OAuth tokens are stored only on a private computer controlled by the operator, in files readable only by the operator's account. Nothing is stored on public servers.

## Limited Use
The app's use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Revoking access
Access can be revoked at any time at [Google Account permissions](https://myaccount.google.com/permissions). The operator deletes the stored tokens when the app is no longer used.
